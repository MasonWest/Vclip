# 2026-04-28 工作记录

## 修复 App.tsx 死黑页面问题

**问题**：Vclip 项目页面打开后一片死黑，视觉特效全部失效。

**根本原因（双重 bug）**：
1. **React Hook 规则违反**：`if (currentPath !== secretPath) return ...` 这行条件返回写在了 `useState`/`useEffect` 之前，导致 React 可能跳过后续所有 hooks，渲染出错。
2. **无效 Tailwind 类**：`bg-radial-gradient` 是 Tailwind v4 的类，在 v3 项目中完全不生效，导致"打破纯黑"的径向渐变层无效。

**修复**：
- 将 404 路径检查的 `if` 语句移到所有 hooks 定义之后（return JSX 之前）。
- 将 `bg-radial-gradient from-... via-... to-...` 替换为内联 `style={{ background: 'radial-gradient(...)' }}`。
